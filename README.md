# akshatdev

Creative developer portfolio built with React and Vite.

## Run Locally

**Prerequisites:** Node.js 20+

1. Install dependencies:
   `npm ci`
2. Run the app:
   `npm run dev`

## Deploy To Vercel

This project is a static Vite site, so it can be deployed directly on Vercel with the default settings.

1. Import the repository into Vercel.
2. Keep the framework preset as `Vite`.
3. Build command: `npm run build`
4. Output directory: `dist`
5. Deploy

No environment variables are required for the current frontend.
